## 这个页面做什么

「记录」Tab 用来记录每天的日常数据。页面顶部的标题会显示当前日期的记录条数，形如「今日记录 · 3 条」；查看的不是今天时，标题显示为「&#123;日期&#125; · 3 条」。

## 切换日期

页面顶部可以切换正在查看的日期：

- **今天**：快速回到当天
- **上一天** / **下一天**：在相邻日期之间前后移动
- **选择日期**：直接跳到某一天

切换日期后，列表与标题都会跟着变化。想补记前几天的数据，先切到那一天再记录。

## 新增一条记录

页面提供按类型划分的快捷入口，例如「记饮水量」，点一下就会打开对应的记录表单。也可以用通用的「记录」按钮，自行选择类型 —— 可记录的类型包括饮水、餐食、体征、心情、症状、活动、备注与睡眠。

记录表单里的字段有：

1. **类型**：这条记录记的是什么
2. **日期** 与 **时间**：这条记录发生在什么时候
3. **单位**：数值的计量单位
4. **标题**：可选，不填也能保存
5. **备注**：补充说明

确认无误后保存，记录就会出现在当前日期的列表里。部分类型（如饮水、睡眠、症状）有专门定制的表单，字段比通用表单更贴合该类型。

## 记录饮水

饮水有专门的快捷入口「记录饮水」，可以直接手动输入毫升数。

饮水的单位有三种：

- `ml`：按毫升记录，适合有量杯或带刻度水杯的情况
- `杯`：按杯数记录
- `次`：按次数记录

> 用哪种单位都可以，关键是每次都记，数据才连贯。单位混用不影响记录，但会让回顾里的趋势不太好比较。

## 记录睡眠

睡眠有独立的记录表单，需要选择**就寝时间**与**起床时间**，两者都填才能保存。此外还可以补充：

- **睡眠类型**：夜间睡眠 / 午睡
- **睡眠质量**：较差 / 一般 / 良好 / 优秀
- **分期时长**：深度睡眠、浅度睡眠、REM 睡眠（单位分钟）

表单会校验时间的合理性，例如醒来时间必须晚于入睡时间、午睡不能跨天且不超过 3 小时、
夜间睡眠不超过 16 小时。

## 记录症状

症状记录采用「点一个即保存」的方式：选择症状后立即写入，不需要再点保存。
如果某种症状可以多选，页面会提示「选择要记录的症状（可多选）」。

每条症状记录可以标注**严重程度**。

## 其它记录类型

除了饮水量、睡眠与症状，还可以记录**备注**类的条目，用来写下当天想留下的一句话或一件事。

> 不同记录类型共用同一套日期与时间字段，因此补记前几天的数据时，记得先切到那一天。
