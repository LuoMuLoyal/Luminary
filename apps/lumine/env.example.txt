# Lumine 环境变量
#
# 本地开发：把需要的行取消注释后放进 `.env.local`（已被 .gitignore 忽略，不进版本库）。
# 生产 / 桌面打包：由 CI secrets 在构建期注入，**不要把真实地址写进仓库**。

# ── Lucent API ──────────────────────────────────────────────
# API 根地址（不含 /api/v1，代码里会补）。
# 默认值：http://127.0.0.1:3000（本机 Lucent 开发实例）
# VITE_LUCENT_API_BASE=http://127.0.0.1:3000

# 是否在请求里携带 httpOnly 会话 cookie。
# 认证依赖它，**默认就是带上**；只有做无凭据探测时才需要改成 omit。
# VITE_LUCENT_CREDENTIALS=include

# ── 说明 ────────────────────────────────────────────────────
# 认证是 httpOnly cookie 会话（Lucent 的 /auth/session/*）：token 由浏览器收下，
# 前端代码读不到。所以这里没有、也不应该有 token / secret 类变量。
#
# 跨域提醒：Lucent 的 CORS_ORIGIN 必须包含本客户端的来源，否则预检失败，
# 而且服务端日志里什么都看不到（请求根本没发出去）。开发期需要
# http://localhost:1420；线上需要 Web 端与桌面端的实际来源。
# 详见 Lucent 的 docs/reference/environment-variables.md。
